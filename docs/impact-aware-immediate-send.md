# メッセージの即時割り込み

Code画面のキュー待ちメッセージにある「即時送信」は、`streamingBehavior: "steer"` と `interruptIfSafe: true` を送る。

- 生成中、または実行中ツールが既知の読み取り専用組み込みツール（`read` / `grep` / `find` / `ls`）だけなら、SDKの実行をキャンセルして新しい指示で続行する。
- 書き込み・シェル・委譲・UI操作・ラッパー・不明なツールは中断しない。通常のsteerとして、現在の生成・ツール呼び出しが終わる安全な区切りに差し込む。名前だけでは読み取り専用と証明できないMCPツールも待つ。
- 圧縮、Goal Loop、権限承認・質問待ち、provider切り替え、停止準備、SDKの既存キュー、複数の通常プロンプトがある場合も中断しない。送信準備中はストリーム開始を待つ。
- 中断は実行済みの変更を巻き戻さない。ユーザーの「停止」と異なり、バックグラウンドの子タスクや他のキューを一括取消しない。
- 中断の完了を確認してから送信するため、キャンセル処理や通信の遅延を含む厳密なリアルタイム保証はない。中断中に停止・取消が来た場合は、新しい指示を勝手に再開しない。

`interruptIfSafe` のない既存のBot/Room/intercom等のsteerは従来どおり、実行を止めず安全な区切りで配送する。
