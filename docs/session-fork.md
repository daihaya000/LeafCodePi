# 会話の分岐

Codeセッションの各ユーザー発言にある **ここから分岐** → **分岐して編集** で、別パターンの会話を始められる。

- 選んだ発言の **直前まで** の履歴を新しいセッションへコピーする。
- 選んだ発言の本文・画像・テキスト添付を分岐先の入力欄に戻す。編集して送信するまでAIは実行しない。
- 元の会話・セッションID・履歴は変更しない。分岐先は新しいIDと「（分岐）」付きのタイトルを持つ。
- プロジェクト・作業ディレクトリ・モデル・思考レベル・エージェント・アカウント・承認設定を引き継ぐ。Botの監督・Goal Loopの実行状態・巻き戻し状態は引き継がない。
- 作業ファイルは共有する。ファイルの巻き戻しやworktreeによる分離ではない。
- 応答・圧縮・承認待ちの間は分岐を拒否する。停止・回答後に再試行する。アーカイブ済みの履歴からも新しい通常セッションを作れる。
- Bot会話・サブエージェントの入れ子履歴には分岐操作を表示しない。

## 実装

`POST /api/tasks/:id/fork` に `{ entryId: string }` を渡す。結果は `{ task, text, images, files }`。

本番WebUIは `action: "fork"` のタスク管理リクエストを所有Backendへ転送する。ランタイム非所有者は履歴やタスクを変更せず、転送失敗時もローカル実行へフォールバックしない。

`web/src/lib/pi/task-fork.ts` は独立したSessionManagerで選択発言の祖先だけを抽出する。元のライブSessionManagerを分岐・巻き戻ししない。最初の発言は空の永続セッションへ分岐でき、登録失敗時は新規セッションのみを削除する。

分岐直後の未送信入力はブラウザタブ内の一時draftとして引き渡す。入力欄に復元された後の再読み込みで未送信内容を永続保存する機能ではない。
