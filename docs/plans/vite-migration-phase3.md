## Increment 1 — pinned production SPA delivery

- `gateway/src/static.mjs` validates an explicit absolute build directory before opening the listener, then pins regular-file bytes in a finite in-memory snapshot (128 MiB/4096 files maximum). Requests perform no filesystem lookup. Editing/deleting that directory afterward cannot change the running generation.
- Dispatch: reject unsafe raw static targets and API paths escaping their namespace; preserve existing API canonical redirects; run the existing auth gate; handle the exact public display bootstrap; handle `/api` and `/api/*` exclusively as API; then serve emitted resources or the seven known extensionless screen routes. Unknown APIs, errors and nonexistent resources never become entry HTML.
- Root/file/directory links, traversal, encoded separators/double escapes, hidden files, NTFS aliases, unknown MIME types, source maps, reserved namespace files, other HTML, missing emitted entry references and HTML without a Vite module entry fail closed. Startup reads use no-follow where available and verify opened file identity and unchanged metadata/size.
- Entry HTML and errors use `no-store`; Vite default eight-character-hashed asset names use one-year immutable caching; other public files revalidate. Assets use weak SHA256 ETags (including compressed representations), GET/HEAD conditional 304, explicit MIME and `nosniff`. HTML never returns a conditional stale 304. HEAD suppresses bytes but retains original content length.
- Only emitted non-HTML resources/resource namespaces become public to load Login. Protected screens/API retain Cookie/Bearer/token-cleanup/rotation/Origin policy. The shared Next public-path policy is unchanged. Missing resource requests return JSON404 rather than Login HTML redirects.
- Default `gateway` start requires `LEAFCODE_PI_SPA_DIR` and fails before listening if absent/empty/relative/missing/broken. It never launches Vite dev/preview. Explicit `--api-only` / `npm run start:api` preserves the P1 transport-only comparison mode; the P1 comparison launcher now opts into it.
- Gateway build permissions add filesystem/hash/path capabilities solely to the static snapshot reader; entry/router/relays still cannot acquire OS/process/SDK/owner capabilities. The frozen business inventory stays **165 routes / 265 operations**, with **252 emitted runtime modules**.
