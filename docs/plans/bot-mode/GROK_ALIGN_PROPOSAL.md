## 優先順位（実装順）

### P0 — 一発で「Grokっぽさ」が出る

#### 1. 右設定パネルの情報設計（`BotView` aside / 将来 `BotSettingsPanel`）
**Grok参照:** 大きな顔 → 名前（編集）→ タイトル/ラベル → 説明 → 通知 → その下に詳細

**差分:**
- アバターをヒーロー扱い（現状80pxは維持可）。下の「タップして画像…」を小さく
- **名前を編集可能に**（いまは読み取り専用の枠だけ）
- **ラベルを編集可能に**（いま固定文言「1:1 アシスタント」）→ `config.title` or `config.label` を想定
- 「説明」を SOUL の上にプレーンテキスト欄、または SOUL 先頭の非コード表示。モノスペース全文は「詳細 / SOUL.md」折りたたみへ
- **通知トグル**（UIのみでも可）: 「このアシスタントについて通知」Grok同型
- モデル / 思考 / スキル / extraRoots / ルーティンは **「詳細設定」セクション** にまとめ、プロフィールと分離
- 削除は最下部・危険ゾーンのまま

**ルーム右ペイン:** 同シェル（ヘッダー＋閉じる＋スクロール）。ヒーローは Users アイコン or メンバー顔スタック。名前編集 → メンバー → 送信モード → 危険ゾーン。

#### 2. ヘッダー操作を Grok 化（`BotChatHeader`）
**差分:**
- アバター＋タイトル行をクリックで右設定をトグル（Grokの名前クリックと同型）
- 「設定」ボタンは **アイコンのみ** またはヘッダーから外して右ペイン依存に
- 戻る矢印はモバイル／狭い幅だけ。デスクトップ3ペインでは左リストがあるので省略可（段階導入）
- ルーム: サブタイトルを「ルーム・N人」のまま、右側にメンバー `BotAvatar` スタック（最大3＋残り）

#### 3. 左リストの密度とアクティブ态（`Sidebar` `BotSidebarBody`）
APIは十分。見た目を寄せる。

**差分:**
- 行パディング: `py-2` → `py-1.5`、アバター28→32、プレビュー `text-[11px]` 維持
- **選択中:** `bg-surface-2` + 左アクセントバー or はっきりした背景（いま hover のみ）
- 時刻: 右上固定、相対表示を統一（「たった今 / 5分 / 昨日 / 日付」）
- セクション見出し「ルーム」「ボット」を sticky・少し強調
- 空プレビュー文言を短く: 「まだメッセージはありません」→「メッセージなし」

---

### P1 — チャット面の質感

#### 4. Composer（`BotComposer`）
**差分:**
- 上ボーダーを薄く、または余白だけで分離（Grokの浮遊感）
- `+` はメニュー予定のまま見た目のみ（円形ホバー維持）
- 送信: 空欄時は無効アイコン円、入力ありでアクセント円（テキスト「送信」は副次でも可）
- フッター行（モデル / 思考 / ルーティン作成）は 1:1・ルームで同じスロット規則。ルームの「部屋に聞く」チップは左寄せのまま

#### 5. バブル
**差分:**
- ユーザー: `bg-accent` 維持、角 `rounded-2xl` + 下右だけ小さく
- アシスタント: **border を外す or `border-border/60`**、`shadow-sm` を弱める／消す
- ルーム: 名前をバブル上に `text-[11px] text-muted`（現状確認して揃える）
- 応答中ドットはバブル列にインライン

#### 6. ライトテーマ・トークン
短いデザイントークン表をコードコメント or `docs` に:

| 用途 | 推奨 |
|---|---|
| ページ背景 | `bg-bg` |
| パネル | `bg-surface` |
| 行ホバー/選択 | `bg-surface-2` |
| 角丸 大 | `rounded-2xl`（Composer・空状態・カード） |
| 角丸 中 | `rounded-xl`（入力枠） |
| 角丸 行 | `rounded-lg` |
| 本文 | `text-sm` |
| 補助 | `text-xs` / `text-[11px] text-muted` |

Codeモード既存トークンを崩さない（Bot面の class 寄せが主）。

### P2 — 一貫性・仕上げ

#### 7. 1:1 とルームの操作感統一
- 設定トグル経路を共通化（ヘッダークリック）
- 右ペイン幅 `22rem` 共通、閉じる位置共通
- 空状態カードのタイポ・余白を同一コンポーネント化（`BotEmptyState`）

#### 8. リストの細かい UX
- 未読ドット（将来。データがなければスキップ）
- 検索フォーカス時のクリアボタン
- 新規作成フォームをリスト下からヘッダー「＋」メニューへ（任意）
