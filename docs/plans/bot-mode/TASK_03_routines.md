# TASK_03 — ルーティン v1（cron）

親ドキュメント: `BOT_MODE_BRIEF.md`  
**前提:** TASK_01 完了済み（TASK_02 は任意）。  
**このタスクだけ実装する。** Computer・イベントトリガは実装しない。

---

## 目的

Bot に紐づくスケジュールルーティンを追加する。Goal Loop とは別物。

---

## 必須

1. 保存: `bots/<botId>/routines/<routineId>.json`  
   - 例: `id`, `name`, `prompt`, `schedule`, `enabled`, `createdAt`, `failureCount`
2. **主入口:** 1:1 会話の「ルーティンを作成」確認カード（承認後に保存）
3. **副入口:** `/bots/[id]` で一覧・有効／無効・削除
4. スケジューラは既存 `host` の流儀に合わせる。アプリ終了中は動かなくてよい（README に明記）
5. 実行時は対象 Bot のホーム cwd・permission・SOUL を使う
6. 結果投稿先（新規スレッド or 固定スレッド）を選んで明記
7. ガード: 最短間隔（例 5 分）、有効数上限、連続失敗で自動オフ
8. テスト + 回帰

## 含めてはいけない

イベントトリガ、ルーム宛て必須化、Docker computer、Goal Loop 統合

## 受け入れ基準

- [ ] 会話カードまたは詳細からルーティンを作れる
- [ ] スケジュールどおり（または検証可能な手動／短縮 cron）に Bot が動く
- [ ] 無効化・削除ができる
- [ ] 失敗連続で自動オフを確認できる
- [ ] Goal Loop が壊れていない
