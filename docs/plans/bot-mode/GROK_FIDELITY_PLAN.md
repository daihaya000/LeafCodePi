## フェーズ（実装順＝コスパ順）

### Phase G1 — 設定P0（最優先・一発でGrokっぽさ）
担当: プロちゃん実装 / デザちゃんレビュー / デバちゃん受け入れ

1. 右設定パネル情報設計（`BotSettingsPanel` 切り出し）
   - 名前・ラベル編集（バグ残りあればここ）
   - 説明をSOUL上に
   - 通知トグル（UI先行可）
   - モデル/思考/スキル/extraRoots/ルーティンを「詳細設定」へ
2. ヘッダークリックで右設定トグル（`BotChatHeader`）
3. ルーム右ペイン同シェル

**Done:** スクショでGrok設定ペインと並べて違和感が小さい。名前/ラベルPATCHが受け入れPASS。

### Phase G2 — リスト密度＋運用感
1. Sidebar密度・選択态・時刻・見出し（提案P0-3）
2. Sidebar pathname重複（持ち越し dirty）解消
3. 通知の実配線（トグルが効く最小実装）。未読ドットはデータあれば

**Done:** 左リストが「Grokの会話一覧」に見える。pathname回帰なし。

### Phase G3 — チャット面の質感（提案P1）
1. Composer見た目（浮遊感・送信円）
2. バブル（border/shadow・ルーム名表示）
3. ライトテーマ・トークン揃え（Codeモード崩さない）

**Done:** 中央チャットを横並びスクショで違和感小。

### Phase G4 — 一貫性＋マーケット相当（提案P2＋α）
1. 1:1/ルーム操作統一・空状態共通化・ルーム顔スタック
2. マーケット相当の最小: Botテンプレ／共有入口（過度なストアはしない。発見・複製ができる最小）

**Done:** 操作経路が一本化。テンプレからBotを1つ立てられる。
