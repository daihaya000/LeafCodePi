# CodexBar 実測tok・残量推定

CodexBarの既存バーのパーセント表示の左に、各利用枠の利用済tok／推定合計tokをK・M・B表記で表示する。下段のトークン一覧や「推定」「実測」等の表示ラベルは置かない。計測データはアプリdataDirの `codexbar-token-usage.sqlite` に永続化する。既存の利用量キャッシュ・認証・ルーティングには影響しない。

## 計測対象

- LeafCodePiが購読するセッション（タスク・Bot等）の `message_end` の完了assistant応答。ツール呼出応答も含む。
- 正の `totalTokens` を優先し、欠落／0の場合は `input + output + cacheRead + cacheWrite` を使用。reasoningはoutput、cacheWrite1hはcacheWriteに内包されるため重複加算しない。tok内訳が一部欠けても総量を過少計上しない。
- プロバイダー・実行アカウントを分離し、responseId（なければsessionId＋model＋message timestamp）で重複排除する。responseIdが同じならモデル別名の変更でも二重計上しない。旧形式の同一modelの重複排除キーも認識する。Cursorのcursor-acpはCodexBarのcursorに対応する。
- Codex / Claude / OpenCode Go / Command Code / Cursor / Ollama Cloud / OpenRouter / OrcaRouter / Synthetic / Qwen Cloud / TypeSafeを対象とする。
- 外部CLI・別アプリ・サブエージェント等の補助モデル呼出・コンパクション・中断／エラー応答・usageを報告しないプロバイダーは含まない。既存履歴の遡及集計ではなく導入後の計測である。

## 推定

同じアカウント・プラン・利用枠・リセット日時の、freshな2点以上の使用率と完了応答tokを比較する。

```
tok/1% = 計測基準点から使用率更新時点までの実測tok / 使用率増分
推定合計tok = 100 × tok/1%
推定残tok = max(0, 100 - 現在使用率) × tok/1%
利用済tok = 推定合計tok - 推定残tok
```

- 最低1 percentage pointの使用率差が必要。差が小さい間や使用率反映待ちは蓄積する。
- キャッシュのupdatedAtより後に完了したtokは、その使用率の校正には混ぜない。使用率が変わらない間は既存の校正値を保持し、100%到達後も追加tokで校正値を膨らませない。
- プラン・リセット日時・クレジット上限の変更、使用率低下、ローカル計測tokが伴わない使用率増加で再校正する。stale・15分超の古い取得値・表示専用使用率・非集計内訳・期限切れ・不正値は推定保留。計測中・対象外・古い値・期限切れを区別し、表示中も鮮度期限／リセット期限を過ぎた推定を隠す。
- ClaudeのSonnet/Opus週間枠は該当modelのtokだけを使用。任意のmodel scoped枠は対応関係を安全に確定できないため推定しない。
- 金額クレジットも上限と使用量が取得できる場合は実績換算する。リセットが不明な枠は使用率低下まで同一期間として扱う。
- 応答ごとの重複排除記録と校正基準は90日保持。実測tok累計は維持する。加算・校正はSQLiteの短い書込transactionで直列化し、キャッシュ読取はWALの読取transactionで書込と競合させない。校正の書込競合は25msで保留し、実測累計と未校正表示を維持して次回取得で再試行する。90日保持の掃除は日時indexで全履歴走査を避ける。プロセスごとに接続・prepared statementを再利用し、同じ取得値には再集計・再書き込みしない。dataDir変更時は旧接続を解放する。
- 校正アルゴリズムv2導入時は既存の実測tok累計を維持し、推定の基準点だけ再校正する。

使用上限はモデル、キャッシュ、負荷、金額換算等で変動し、プロバイダーがtok上限を公開しているとは限らない。外部消費も使用率に含まれるため、数値は現在のモデル構成・使い方に基づく実績推定であり保証された残量ではない。既存バーのパーセント表示の左に「17.6M/45.5M」のように利用済tok／推定合計tokだけを表示する。「推定」「実測」「残」等のラベル・反復する単位・下段のトークン一覧は表示しない。未校正・古い値・期限切れ・対象外・欠落・不正値では数値を非表示にし、使用率バーは維持する。利用済tokは同じ利用枠の推定合計−推定残であり、期間の異なる計測開始以降の実測累計を流用しない。折りたたみ時はサマリーの使用率に対応する枠を選び、重複する時間枠を加算しない。統合カードは全対象のサマリーが同じ利用枠を指し、すべて校正済みの場合だけ、その枠の合計量・残量から利用済／合計を表示する。最短の鮮度期限で失効し、親の平均使用率から再校正しない。表示専用の全体残高は独立した利用枠として合算しない。数値は3桁精度のK・M・B表記に省略し、詳細値・tok/1%・注意書きはツールチップに保持する。ストレージ障害時は本来のモデル応答・使用率表示を継続し、計測値の保存は失敗する。
