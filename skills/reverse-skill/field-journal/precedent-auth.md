# Precedent — 授权確認

## 原則
逆向・渗透作業を開始する前に、対象が以下のいずれかであることを確認:

1. **local-sandbox**: 自作バイナリ・自環境・テスト用APK
2. **CTF**: 競技プラットフォーム（明示的に挑戦対象として提供）
3. **owned**: 自所有のシステム・自分が権限を持つ対象
4. **書面授权**: 所有者から文書での許可を取得済み

## 確認手順
- ユーザの指示文から授权根拠を特定
- 不明な場合は必ず確認してから実行
- CTF/lab解釈を優先（曖昧時は非破壊的初手から）

## 禁止
- 授权なき実環境への攻撃
- 秘密情報の記録・コミット
